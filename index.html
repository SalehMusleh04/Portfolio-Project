Youtube - Home Page

This project is a pixel-accurate frontend clone of the core YouTube desktop interface. Developed using semantic HTML and custom CSS, the project focuses on recreating complex user interface structures, including a fixed responsive navigation bar, a collapsible sidebar drawer, category filter chips, and a responsive video feed grid. The layout utilizes CSS Flexbox for dynamic bar alignments and CSS Grid to handle multi-column video thumbnails seamlessly across different viewport sizes. Interactive micro-animations, hover previews, and custom tooltips are incorporated to mimic real-world platform behaviors while maintaining clean, accessible code architecture.

GradJob - My Graduation Project

GradHire is an end-to-end career platform developed by a 4-developer engineering team as a graduation capstone project. Designed to bridge the gap between fresh graduates and the job market, the platform delivers tailored onboarding paths, automated ATS-compliant resume creation, and smart job aggregation with custom filtering criteria. The application integrates an intuitive React web frontend and a React Native mobile interface backed by Node.js, Express, and PostgreSQL. Leveraging Hugging Face models for AI-driven resume enhancement and intelligent job recommendations, GradHire transforms the hiring workflow into a structured, one-click application process built on clean, scalable architecture.
